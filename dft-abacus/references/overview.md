# ABACUS v3.10.1：范围与证据

本 skill 面向 ABACUS 输入准备、计算流程、精度和结果判读，覆盖 PW/LCAO、SCF、结构优化、AIMD、电子结构、磁性和可选高级模块。运行需要相应功能的 ABACUS 可执行文件及实际外部数据；回答用法与审核输入不要求本机已有二进制。

基线为本地源码 tag `v3.10.1`、commit `f71921fe848659deac8db319cd4311b55b5ad480`。
原有文档摘录已按实现修订；[源码依据](source-audit.md)记录入口和复核方法。
实现中的注释与手册也可能过时：必须结合参数读取、重置、检查及实际调用链判断。

- PW 的平面波完备性、LCAO 的轨道完备性以及实空间积分网格是不同的精度来源；提高 LCAO 的 `ecutwfc` 不能代替扩大轨道基组。
- INPUT、STRU、k 点采样和外部数据共同决定计算；KPT 并非总需预先提供，自动生成会覆盖所选文件。
- `calculation` 决定任务，`esolver_type` 决定能量求解路线，`ks_solver` 决定相应电子求解方法；三者组合有约束。
- 电子温度、离子温度和 DOS 绘图展宽是三个独立量；本版温度关键词换算必须读[有限电子温度](finite-temperature.md)。
- 收敛不等于完成迭代步数，也不等于数值精度和物理模型已经可靠；能量、力、应力、磁态与占据分别检查。
- 输入被解析成功不能证明所需库已编译、外部文件相配或目标物理量正确。GPU、DFT+U、EXX 等要按各自实现分支判断，不能沿用跨版本的统一禁令。

任务导航见[入口](../SKILL.md)与[能力索引](capability-index.md)。源码静态审核和局部源码执行测试的结果见[验证记录](../test-results.md)；它们不代替实际材料体系的收敛测试。
