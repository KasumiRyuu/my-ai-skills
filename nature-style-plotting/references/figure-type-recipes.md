## 选择图型

先写出读者要完成的比较任务：

| 任务 | 优先图型 |
|---|---|
| 随连续自变量变化 | 点 + 线、误差棒、区间带 |
| 比较独立组别 | 点图、箱线/小提琴 + 原始点、必要时柱图 |
| 展示分布 | ECDF、直方 step、KDE、箱线或小提琴 |
| 展示二维连续场 | `pcolormesh`、`imshow`、等值线 |
| 展示状态区域 | 相图、分类区域 + 边界 + 数据点 |
| 展示谱或衍射 | 原始/处理谱、拟合、残差、峰位或 Bragg ticks |
| 展示空间结构 | 原子快照、显微图、地图或剖面 |
| 解释机制 | 矢量示意图、流程图、受约束的概念图 |

如果两个变量都连续，不要先任意分箱再画柱图。若样本量小，不要只显示均值；若关系是机制
或路径，不要用饼图。

## 线图、散点与模型比较

- 数据点与模型线分层：点表示观测/计算样本，线表示拟合、理论、插值或引导视线。
- 不要连接本质离散的样本、跨越缺失区间或跨越能带路径重置点。
- 多系列先减少 marker 密度，再增加颜色数量。必要时使用 `markevery` 或只画部分标记。
- 基准、文献或一比一线用中性灰和较低视觉层级；主结论线比辅助线略粗或更深。
- 拟合必须报告模型、区间、权重和不确定度；不要把拟合线画到未经约束的范围而不标外推。
- 直接标签适合 2--4 条分离良好的曲线；密集交叉曲线使用紧凑图例和冗余线型。

### 压力、温度和 Arrhenius 图

- 轴上明确 GPa、K、S m⁻¹、W m⁻¹ K⁻¹ 等单位。
- 使用 `1/T`、`1000/T` 或对数电导时，在轴标签和处理代码中明确变换。
- 不同相、晶向、含水量或成分使用稳定的颜色与 marker 映射，跨面板保持一致。
- 地温线、等温线和相边界不是普通数据系列，应以不同视觉语法和来源注释区分。

## 误差与不确定度

- 稀疏独立点：误差棒，并给出 SD、SE、CI、仪器误差或传播误差定义。
- 连续趋势：窄透明带；边界线可省略或使用轻线，避免形成第二条“数据线”。
- 模型集合：可显示中位数 + 区间，或少量低透明度成员；不要用不透明 spaghetti plot。
- 非对称误差使用非对称 errorbar，不强行对称化。
- 误差范围被坐标裁切、对数轴无效或超出物理边界时，必须显式处理并报告。
- 图注说明 `n`、区间类型及是否包含模型和测量两类不确定度。

## 相图与稳定区

相图同时包含分类区域、边界、观测/模拟点和路径，不能用普通折线图思维处理。

- 相区使用低饱和浅填充，文字直接标在面积足够的区域内；小相区用引线而非极小字体。
- 一阶边界、连续转变、亚稳边界、外推和文献边界使用不同线型，并在图例或直接标签中说明。
- 实验点、从头算点、机器学习势结果和文献点使用不同 marker；颜色不要与相区混淆。
- 共存区宽度和边界不确定度使用带状区域，不把中心估计画成精确锐线。
- 地温线、冲击 Hugoniot、行星路径或等熵线使用独立中性色或高对比色，标明来源。
- 相区填色不能遮蔽数据点；将数据点和关键边界置于更高 `zorder`。
- 只在热力学上有明确意义时插值，不能用平滑等值线制造未经计算的相界细节。

## 二维场、热图与等值线

- 规则矩阵可用 `imshow`；非等间距物理网格用 `pcolormesh`。
- 连续单调量使用感知均匀顺序色表；正负异常围绕物理零点使用发散色表和固定中心。
- 跨面板比较同一量时共享 `norm`、范围和一个色条。若范围必须不同，在面板上明确标示。
- 分类相态使用离散色表和明确边界，不用连续渐变暗示不存在的中间状态。
- 过度插值会伪造空间结构；默认展示网格真实分辨率，必要时叠加采样点。
- 等值线标签只保留关键水平，避免每条线都写值。色条标签包含物理量与单位。
- 叠加矢量场时下采样箭头并提供 quiver key；箭头不应遮蔽底图。

## 衍射与光谱

### XRD / 衍射

- 观测强度使用黑色/深灰；拟合曲线用主色；差值曲线放在独立偏移基线。
- Bragg 反射用短竖线按相分组，并与相名称建立稳定颜色映射。
- 背景、峰拟合和总拟合必须能区分；不要用同色实线叠在一起。
- 若强度归一化、截断或取对数，轴和图注必须说明。
- 二维衍射图保留真实动态范围、beam stop 和掩膜说明；不要用彩虹色表掩盖弱峰。

### Raman / IR / 一般谱图

- 保留原始峰位和线宽；平滑、基线扣除和归一化必须记录。
- 多条谱可纵向 offset，但需明确“offset for clarity”，不让读者误解绝对强度。
- 峰指认使用短引线或窄色带，避免大量文字压在谱线上。
- 对温压序列，采用有序色表或少数分组颜色，并提供端点值；不使用无序彩虹。

## 能带、声子与态密度

- 高对称路径分段绘制，禁止跨路径重置点连线；高对称点使用竖直浅线。
- 能带统一费米能或价带顶零点；声子谱保留零频线并清楚显示虚频。
- DOS 与能带共享能量轴和零点；投影 DOS 颜色与元素/轨道图例一致。
- 自旋通道可使用上下镜像、不同线型或相邻面板；不能仅以难区分的红绿表示。
- 参考 DFT、机器学习势和实验数据使用颜色 + 线型双编码。
- 密集曲线优先降低辅助线不透明度，不要把每条支都加 marker。

## 原子结构与模拟快照

- 使用领域通用或项目固定的元素配色，并在整篇保持一致；图例列出不直观的元素颜色。
- 球半径表达元素身份或配位，不应被误解为真实原子半径，必要时说明。
- 展示晶胞边界、晶向、尺度或切片方向；透视图若会扭曲距离判断，增加正交投影或第二视角。
- polyhedra 用半透明低饱和填充；键线仅在有科学定义时显示。
- 扩散轨迹或概率云与静态原子分层，避免轨迹完全遮住结构。
- 复制晶胞、省略原子、隐藏物种或选择时间帧必须服务于结论，并在图注说明。
- 从 VESTA、OVITO、ASE 等工具导出后，在矢量层统一标签、箭头和字体；不要以截图作为最终图。

## 分布与统计图

- 样本较少时显示所有点；箱线/小提琴只是摘要，不替代原始分布。
- 多组直方图优先 `step`、ECDF 或小倍图，避免半透明填充叠成泥色。
- 箱线图说明 whisker；小提琴图说明核密度和带宽；误差条不冒充分布。
- 对数长尾数据在合适的轴上显示，并保留零值/非正值的处理记录。
- 随机 jitter 固定种子，仅改变显示位置，不改变统计。
- 多重比较、显著性和样本量写在图注或简洁标注中，避免星号墙。

## 显微图、照片与实验图像

- 保留原始纵横比、像素和动态范围；禁止拉伸、无说明裁切或选择性局部增强。
- 同组图使用相同亮度/对比度处理；任何去噪、反卷积或伪彩色步骤可追溯。
- 比例尺来自标定而不是估算，颜色与背景高对比；同组面板尽量使用相同尺度。
- 颜色通道给出清晰图例，并提供形状、边界或灰度可读性；不要只靠红绿通道。
- 箭头和轮廓只标关键结构，线宽和箭头头部在最终尺寸下可见。
- 照片背景、样品方向和实验条件一致；装置照片与科学数据不要混用同一种色标。

## 地学剖面、地图、流场与行星内部

- 深度、半径、纬度、经度、压力和温度轴必须有方向与单位；必要时提供次轴转换。
- 地层、相区或行星层使用低饱和填充，边界线和文字保持高对比。
- 地温线、绝热线、熔化线和相边界使用稳定线型；来源写入图注。
- 地图选择与科学问题一致的投影，不让面积或距离失真影响结论。
- 连续场使用感知均匀色表；异常场才使用以零或参考值为中心的发散色表。
- 流线、磁力线和箭头需有方向、尺度或 key；稀疏化显示但用完整场计算统计量。
- 三维球壳或行星截面提供经纬/半径方向和观察视角，避免纯装饰性球体。

## 科学示意图与工作流

示意图适用于机制、装置、几何和流程，不适合替代真实数据。

### 视觉语法

- 优先平面矢量图：统一 0.5--1 pt 边线、圆角、箭头和有限色板。
- 每种颜色对应稳定对象或过程，例如固相、液相、离子、电子、热流；不使用无语义渐变。
- 箭头表示方向、通量、因果或步骤，并通过颜色/线型区分这些含义。
- 真实几何按比例绘制；概念图明确标注 `not to scale` 或在图注说明。
- 文字使用短名词和物理量，解释性句子留给图注。
- 层次按阅读顺序排列，避免交叉箭头；复杂流程拆成多个面板。

### 物理一致性

- 温度梯度、热流、电势、电流、离子迁移和磁场方向必须相互一致。
- 正负电荷、氧化态、边界条件和坐标方向不得为美观而随意翻转。
- 晶体/原子示意应由结构数据或可信软件生成，不能凭想象画出定量结构。
- 实验装置保留关键组件和测量路径；省略部分不应改变读者对边界条件的理解。
- 生成式位图只能作为非证据性的概念插画候选，不能冒充实验、显微、光谱或模拟结果。

### 实现

- 简单示意图可用 Matplotlib patches 或直接生成 SVG；复杂结构由专业工具导出后统一排版。
- 文字、箭头、轮廓、比例尺和图例保持矢量可编辑。
- SVG/PDF 中检查字体嵌入、裁切、透明度和图层叠放。

## 多面板复合图

先为每个面板定义角色，再决定网格：

```text
对象/方法 -> 直接证据 -> 定量比较 -> 机制/外推
```

- 面板标签按目标期刊习惯使用 `a, b, c` 或 `A, B, C`，位置和字体一致。
- 不要求所有面板等宽等高；照片、谱图、相图和窄色条按信息量分配空间。
- 跨面板共享相同变量时共享颜色、marker、范围和单位。
- 公共图例和色条放在网格之外或专用区域，不在每个面板重复。
- 只在确有比较价值时共享坐标；不同物理量不要为了整齐强行同尺度。
- 栅格图像在原始分辨率下放置，矢量图层在最终软件中叠加。
- 主文图删除次要参数和重复面板；SI 可以展开但沿用同一视觉词汇。
